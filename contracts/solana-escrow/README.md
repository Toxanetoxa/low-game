# LOW GAME · ставки на SOL

Программа хранит взносы игроков в лампортах. Два одинаковых подтверждения перечисляют банк победителю. При ничьей или разных решениях каждый получает свой взнос. Если срок прошёл, возврат может запустить любой плательщик комиссии. При расчёте программа перечисляет SOL прямо на адреса игроков.

На каждую комнату создаётся отдельный счёт PDA из `duel`, адреса создателя и UUID комнаты. Создатель оплачивает хранение 96 байт состояния и комиссию за создание. Счёт хранит итог дуэли после выплаты, чтобы старые подписанные транзакции не могли примениться к новой дуэли по тому же адресу. Минимальный взнос равен сумме, которую сеть требует для счёта кошелька без данных.

Для сборки нужны Rust, Agave CLI и `cargo-build-sbf` версии 4.2.0 или новее. Команда из этой папки создаёт `target/deploy/low_game_solana_escrow.so`. [Сборка Solana-программ для sBPFv3](https://www.anza.xyz/blog/migrating-solana-programs-to-sbpfv3)

```sh
cargo build-sbf --arch v3 --tools-version v1.57 -- --locked
```

Проверки подтверждения исхода и возврата по сроку запускаются командой `cargo test --locked`.

Чтобы проверить программу локально, создайте отдельный ключ программы и загрузите её при запуске валидатора.

```sh
solana-keygen new --no-bip39-passphrase --outfile local-program-keypair.json
solana-test-validator --bpf-program local-program-keypair.json target/deploy/low_game_solana_escrow.so
```

Для разработки укажите `VITE_SOLANA_RPC_URL=http://127.0.0.1:8899` и задайте `VITE_SOLANA_ESCROW_PROGRAM` равным публичному адресу программы. Его печатает `solana-keygen pubkey local-program-keypair.json`.

Для публикации игры со ставками на SOL сначала разверните программу в Devnet с отдельного кошелька, пополненного тестовыми SOL. Используйте адрес развёрнутой программы в `VITE_SOLANA_ESCROW_PROGRAM` при сборке игры. [Развёртывание программы Solana](https://solana.com/docs/programs/deploying)
